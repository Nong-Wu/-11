# 팀 프로젝트 규칙

## 1. 역할 분담
- 팀원 6명은 각자 담당 주제를 하나씩 맡는다.
- 각 팀원은 담당 주제의 MD 파일을 작성하고 수정한다.

## 2. 브랜치 관리
- `main` 브랜치는 최종 결과물 관리용으로 사용한다.
- 개인 작업은 별도의 브랜치에서 진행한다.
- 작업 완료 후 Pull Request(PR)를 통해 병합을 요청한다.
- `main` 브랜치에 직접 수정 사항을 반영하지 않는다.

## 3. 파일 작성
- 파일명은 영문 소문자와 하이픈을 사용한다.
- 모든 MD 파일은 공통 문서 양식을 따른다. 
- README에는 각 주제별 MD 파일 링크를 추가한다.(먼저 개인md파일 다 만든 후에 리드미 파일 만들게요)

## 4. 커밋 및 병합
- 커밋 메시지는 수정 내용을 알 수 있도록 작성한다.(한글로)
- PR에는 변경 사항과 수정 목적을 간략하게 설명한다.
- 병합 전 다른 팀원 1명 이상의 검토를 받는다.

## 5. 자료 및 출처
- 사실에 근거한 자료를 작성한다.
- 외부 자료를 활용하면 출처와 링크를 표시한다.
- 다른 자료를 그대로 복사하지 않고 직접 정리한다.

## 6. 소통 및 일정
- 작업 시작, 완료, 지연 상황을 팀 채팅방에 공유한다.
- 담당 작업의 마감일을 준수한다. 10/17 토 오전?까지
- 제출 전 문서 형식, 오탈자, 링크를 점검한다.
